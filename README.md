# 🌐 Thomas Piessat — Software Engineer Portfolio

This repository contains the source code for my personal portfolio website: [thomaspiessat.fr](https://thomaspiessat.fr/)

## 🚀 About

I’m a **Software Engineer** specialized in **C++**, **C#**, and **game development**.  
This site showcases my work in:
- **Unreal Engine 5** and **Unity** tools
- Gameplay programming
- Technical art & plugins
- Personal and professional projects

## 🛠️ Built With

- **React.js** — Frontend framework
- **React Bootstrap** — UI components
- **i18next** — Internationalization (English / French)
- **Custom dark / light themes**
- **React Router** — Client-side navigation

## 🌍 Features

- Light / dark theme switch  
- English / French language support  
- Animated page transitions  
- Project categories (Professional, Personal, Student)  
- Downloadable résumé (FR & EN)  
- Responsive design for mobile and desktop
